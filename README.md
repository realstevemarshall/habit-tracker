# Habit & Exercise Tracker

A zero-cost, local-first habit and exercise tracker built with React, Vite, Tailwind CSS, and Recharts. All data is stored in `localStorage` — no backend required.

## Features

- **Exercise tracking** — Push-ups, sit-ups, pull-ups, and miles with yearly goals, progress bars, and pace charts
- **Daily habits** — 11 checkboxes with definition tooltips
- **Weekly fast** — Track progress toward 52 fast days per year
- **Quarterly 96-hour fasts** — Four fixed windows with optional start/end dates
- **Dashboard** — Summary stats and countdown to 50th birthday (July 24, 2027)

## Getting Started

```bash
npm install
npm run dev
```

Open the URL shown in your terminal (typically `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
